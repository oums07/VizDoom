# Projet d’apprentissage par renforcement avec ViZDoom

Projet étudiant réalisé dans le cadre de notre formation à l’ENSISA.

## Objectif

Développer en Python un agent capable d’apprendre à jouer dans un
environnement ViZDoom grâce à l’apprentissage par renforcement.

## Organisation du projet

Le code que nous développons se trouve dans le dossier
[`reinforcement_learning/`](reinforcement_learning/).

Le fichier [`explication.md`](reinforcement_learning/explication.md)
présente les étapes réalisées, le rôle des fichiers et le fonctionnement
du code pour faciliter sa compréhension et la reprise du travail par
les membres du groupe.

## Travail prévu

- Préparer l’environnement et choisir un scénario.
- Développer et entraîner un agent DQN en Python.
- Évaluer ses performances et les comparer à celles d’un agent aléatoire.
- Analyser les résultats obtenus.

## Technologies

- ViZDoom
- NumPy
- Pillow
